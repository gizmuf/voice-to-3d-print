# Help Pulsai 3D without coding

You do not need to install anything, fork the repository, or understand CAD.
The most valuable help is one real attempt followed by specific feedback.

## Before you start

- Use **Chrome or Safari**. If the Google button is blank, leave in-app browsers
  such as Codex, Instagram, or Facebook and open the same link in Chrome or Safari.
- You will sign in with Google so your projects and files stay private.
- No coding and no API key are required for this test.
- Ignore jewelry / Meshy / Tripo options on the first screen. They are not part
  of this test.

## Ten-minute test

1. Open [3d.pulsai.app](https://3d.pulsai.app) in Chrome or Safari.
2. Sign in with Google.
3. In the first box, type `Create a simple phone stand for an iPhone` or click
   **Stojak na telefon**, then click **Utwórz model**. Wait up to one minute.
4. After the 3D preview appears, use the lower chat box `Napisz do Pulsai…` to
   send 1–2 simple edits, for example:
   - `Make it 20% wider`
   - `Make the base thicker, 8 mm`
5. After each edit, check the **Width** / **Base Thickness** sliders and the 3D
   preview. Do not treat a chat confirmation as success if the sliders snap back.
6. If the sliders return to the first values, stop and report that. Do not keep
   sending more edits.
7. Click **Export** and choose **Export for 3D printing** or the visible **STL**
   button. A file should download. You do not need a 3D printer.
8. Optional GitHub: open
   [github.com/gizmuf/voice-to-3d-print](https://github.com/gizmuf/voice-to-3d-print).
   Click **Star** only if you actually liked the product. Then click
   **Issues → New issue → Non-coder feedback**.
9. If GitHub feels too hard, send the same answers privately. That still counts.

AI-assisted editing may request a provider key. You can stop there and still
report the experience; you are not expected to buy anything to help test the
free deterministic path.

## What to report

A useful report answers five questions:

- What were you trying to make or change?
- Did the first model appear, and did later edits stay visible?
- Did Export download a file?
- What was most confusing or broken?
- Which device and browser did you use?

A screenshot helps, but remove email addresses, provider keys, private model
names, customer data, and anything else you would not post publicly. For a
security or privacy problem, use the private route in [`SECURITY.md`](../SECURITY.md).

## Stars and sharing

If you genuinely find the project useful or want to follow it, starring the
[GitHub repository](https://github.com/gizmuf/voice-to-3d-print) is welcome. A
star is optional and should reflect real interest. Do not fork the repository
unless you actually plan to work with the code.

The strongest support is to share Pulsai 3D with one maker, designer, engineer,
or 3D-printing user who has a real part to try. Ask them for the same short test
and honest feedback.

# Jak pomóc Pulsai 3D bez programowania

Nie musisz nic instalować, forkować repozytorium ani znać CAD. Najcenniejsza
pomoc to jedna prawdziwa próba i konkretny feedback.

## Zanim zaczniesz

- Użyj **Chrome albo Safari**. Jeśli przycisk Google jest pusty, wyjdź z
  przeglądarki w aplikacji i otwórz ten sam link w Chrome albo Safari.
- Zalogujesz się przez Google, żeby Twoje projekty i pliki zostały prywatne.
- Do tego testu nie trzeba kodować ani podawać klucza API.
- Zignoruj opcje biżuterii / Meshy / Tripo na pierwszym ekranie. To nie jest
  część tego testu.

## Test w 10 minut

1. Otwórz [3d.pulsai.app](https://3d.pulsai.app) w Chrome lub Safari.
2. Zaloguj się przez Google.
3. W pierwszym polu wpisz `Create a simple phone stand for an iPhone` albo
   kliknij **Stojak na telefon**, potem **Utwórz model**. Poczekaj do minuty.
4. Gdy pojawi się podgląd 3D, kolejne zmiany wpisuj w dolnym polu
   `Napisz do Pulsai…`, np.:
   - `Make it 20% wider`
   - `Make the base thicker, 8 mm`
5. Po każdej zmianie sprawdź suwaki **Width** / **Base Thickness** i podgląd.
   Potwierdzenie w czacie nie wystarczy, jeśli suwaki wrócą do starych wartości.
6. Jeśli suwaki wrócą do pierwszych wartości, przerwij i zgłoś to. Nie wysyłaj
   kolejnych poprawek.
7. Kliknij **Export** i wybierz **Export for 3D printing** albo widoczny przycisk
   **STL**. Powinien pobrać się plik. Nie musisz mieć drukarki 3D.
8. GitHub jest opcjonalny: otwórz
   [github.com/gizmuf/voice-to-3d-print](https://github.com/gizmuf/voice-to-3d-print).
   Kliknij **Star** tylko jeśli produkt Ci się naprawdę podoba. Potem
   **Issues → New issue → Non-coder feedback**.
9. Jeśli GitHub jest za trudny, wyślij te same odpowiedzi prywatnie. To też się
   liczy.

Edycja przez AI może poprosić o klucz dostawcy. Możesz wtedy przerwać i nadal
opisać doświadczenie — nie oczekujemy, że kupisz cokolwiek, aby przetestować
bezpłatną ścieżkę deterministyczną.

## Co napisać

- Co próbowałeś zrobić lub zmienić?
- Czy pierwszy model się pojawił i czy późniejsze poprawki zostały na ekranie?
- Czy Export pobrał plik?
- Co było najbardziej niejasne albo zepsute?
- Jakiego urządzenia i przeglądarki użyłeś?

Zrzut ekranu pomaga, ale usuń adres e-mail, klucze API, prywatne nazwy modeli i
dane klientów. Problem bezpieczeństwa lub prywatności zgłoś prywatnie według
[`SECURITY.md`](../SECURITY.md).

Jeżeli projekt naprawdę Ci się podoba lub chcesz go obserwować, możesz dać mu
gwiazdkę na [GitHubie](https://github.com/gizmuf/voice-to-3d-print). Gwiazdka
jest dobrowolna i powinna oznaczać prawdziwe zainteresowanie. Nie rób forka,
jeśli nie planujesz pracować z kodem.
